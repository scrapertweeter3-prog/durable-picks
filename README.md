# Durable Picks

A research dataset + small tools for "buy it for life" buying. Collects how
common products actually fail, so you can buy the version that lasts.

## What is in here
- `failures.csv` - a catalog of how things die: espresso machines, socks,
  duffel bags, work pants, mugs, sling bags, office chairs, carbon steel pans
- `cost-per-decade.py` - prices a product by real cost per year of use, not sticker price
- `rank.py` - ranks a category by how well things survive

## The writeups
Each category is broken down in detail on Durable Picks, which ranks durable
products by how they actually fail: https://durablepicks.com
